## 二、爆品页面结构分析

### 典型导航结构
```
顶部：Logo | 搜索 | 账户 | 购物车
主导航：类目1 | 类目2 | 类目3 | Sale
Hero区：全屏大图/视频轮播
信任栏：免费退货 | 安全支付 | 客服热线
品类专区：新品 | 热销 | 场景分类
用户评价：真实买家秀
底部：关于我们 | 帮助中心 | 社媒链接
```

### 产品页结构（转化关键）
```
产品主图（多图切换）
产品标题（品牌+核心词+场景）
价格 + 促销标签（如有）
变体选择（颜色/尺码）
购买按钮（Add to Cart）
物流信息（预估到达日期）
用户评价（星级+文字+图片）
相关推荐（你可能也喜欢）
FAQ折叠区
```

## 三、爆品标题写法

### 公式
```
品牌名 + 核心卖点 + 场景/功能词
```

### 示例
```
✅ Gymshark Women's Vital Leggings 2.0 - High Rise Sweaty
✅ Kylie Cosmetics Matte Lip Kit - Birthday Suit
✅ Allbirds Tree Dasher 2.0 - Sustainable Running Shoe
✅ Portable Blender - USB Rechargeable, 12H Battery Life
✅ Dog Nail Grinder - Low Noise, USB Charging, 3 Speed Modes
```

### 避坑
```
❌ 太长（超过15个词）
❌ 纯关键词堆砌（无品牌感）
❌ 缺少差异化词
```

## 四、产品描述写法

### 黄金结构
```
【第一行】核心价值主张（一句话，5-10词）
【中间段】材质/规格 + 使用场景 + 核心卖点（3-5行）
【信任背书】用户证言/数据 + 品牌承诺
【底部】购买理由（物流/退货/质保/客服）
```

### 示例
```
【第一行】Why You'll Love It
Perfect for daily workouts, made with sweat-wicking fabric that keeps you cool and confident.

【中间段】
• 4-way stretch fabric moves with you
• High-rise waistband for full coverage
• Moisture-wicking technology
• Flatlock seams prevent chafing

【信任背书】
⭐ 4.8/5 from 2,000+ reviews
"The best leggings I've ever owned!" — Sarah M.

【底部】
📦 Ships from US warehouse, 3-5 business days
🔄 30-day hassle-free returns
💬 24/7 customer support
```

## 五、图片风格规范

### 首图（最重要）
- 白底或纯色背景（电商标准）
- 产品占图80%以上
- 正面或45度角
- 无水印/无文字

### 多角度图
- 正面 / 侧面 / 背面 / 细节
- 至少5张起

### 场景图
- 真人使用场景（生活化）
- 不要过度修图

### 图片尺寸
- 主图：2000x2000px（Shopify 推荐）
- 宽屏：1500x1000px
- Story/短视频：1080x1920px

## 六、定价策略参考

### DTC 定价公式
```
售价 = （1688拿货价 × 1.3 + 国内运费）/ 0.7
       ÷ 7.2（汇率）
       + 专线运费（$8-15）
       + 平台手续费（2-3%）
       + 广告成本预留（售价的15-20%）
```

### 示例
```
1688拿货价：¥45（约$6.2）
国内运费：¥5
货本合计：$6.8

物流成本：$12
平台手续费（2%）：约$1.5（售价$75计算）
广告预留（15%）：$11.25

最低定价：($6.8 + $12 + $1.5 + $11.25) / 0.7 ≈ $45
建议售价：$55-65（有利润空间）
```

## 八、成功品牌共同特征

1. **至少1款让人记住的爆品** — 不是100款平庸产品
2. **品牌故事清晰** — 创始人故事/使命/差异化
3. **极简页面，信息完整** — 不堆砌
4. **移动端优先** — 78%流量来自手机
5. **用户评价真实** — 至少10+带图评价
6. **物流承诺明确** — 客户知道什么时候到
7. **退换政策友好** — 降低购买顾虑

## 十一、给新手的核心建议

1. **不要做杂货铺** — 先聚焦1个品类，3-5款产品打透
2. **第一款产品决定生死** — 花2周调研，不要凭感觉选品
3. **先验证再放大** — $20/天测试2周，有数据再追加
4. **图片是第一位** — 好的图片可以让转化率翻倍
5. **物流是信任来源** — 专线小包10-15天，说清楚
6. **复购比拉新便宜5倍** — 做好邮件/短信触达
