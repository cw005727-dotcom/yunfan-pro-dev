# What is catalog?

Note:

This resource is available for Mexico and Chile with logistic type fulfillment.

Currently, sellers can create catalog publications with the content (titles, photos, descriptions and data sheet) provided by Mercado Libre. Listings can be made from current publications and thus compete with other sellers having the best sales conditions to gain exposure on the Product Page. These Pages are positioned in the first places of the search results.

In addition, you can [see more information in the Seller Learning Center](https://sellers.mercadolibre.com/news/catalog-is-here-a-new-way-to-sell-more/).

Now, develop catalog by following this guide!
