## Functional permissions

When creating an application, you must configure the functional permissions of your integration. These will be necessary for user authorization to your application, granting the Grant and allowing the correct use of our API on their behalf.

Note:

Before creating an application, make sure that the account you are using is **the owner account** in the solution you are intending to develop, thus avoiding potential account transfer issues in the future. We recommend that the account is created under a legal entity.

These are the permissions available for setting up your integration:

[Access our DevCenter](https://developers.mercadolibre.com.ar/devcenter).

## Scopes

- **Read only:** allows the use of API GET HTTPS methods.
- **Read and write:** allows the use of API PUT, POST and DELETE HTTPS methods.

## Users (default)

This permission is active by default in all created applications. It allows consumption of **users** resources, allowing you to obtain information from a Mercado Libre registered and authorized account.

## Error due to Lack of Permissions

The following error is returned if your integration does not have access to the resource due to the absence of the corresponding functional Permission:

**Response:**

```javascript
{
"code": "PA_UNAUTHORIZED_RESULT_FROM_POLICIES",
"blocked_by": "PolicyAgent",
"message": "At least one policy returned UNAUTHORIZED.",
"status": 403
}
```

To solve this, you must access your application settings and enable the associated functional Permission by activating the read and write scopes.
